## 通知・ダイアログ

### グローバル通知

|項目|仕様|根拠|
|---|---|---|
|状態|`AppState` は `toast_message: Option<String>`、`ToastKind`、世代番号、`toast_autohide`、`toast_progress` を持つ。`ToastKind` は `Info` / `Success` / `Error`。`toast_progress` が立っている通知は Spinner を添え、同じ id で置き換わる（進捗で積み直しても増えない）。|`crates/app/src/app_state.rs:90`|`crates/app/src/app_state.rs:34-112,341-349`|
|初期値|メッセージなし、種別 Info、世代番号 0。|`crates/app/src/app_state.rs:219-258`|
|発火|`set_toast_kind` は種別を設定してからメッセージを設定する。`set_toast` は世代を増やし、遅延実行で Workspace を再描画する。進行中は `set_progress_notice`（5 秒で自動消滅。進捗のたびに積み直す）と `set_sticky_progress_notice`（自動で消えない。終了時のアップロード用）を使う。|`crates/app/src/app_state.rs:565,574`|`crates/app/src/app_state.rs:351-375`|
|消費|Workspace は世代変更時のみメッセージを GPUI NotificationType に変換し、元メッセージを直ちに消去する。|`crates/app/src/workspace.rs:1152-1174`|
|表示位置・時間|Notification レイヤーは右上。コードコメント上の gpui-kit 既定自動消去時間は 5 秒。アプリ側で明示的な 5,000 ms 指定はしていない。進行中の通知は本文の下に Spinner（`notice-progress`）を出す。|`crates/app/src/workspace.rs:1348`|`crates/app/src/workspace.rs:1270-1274`|
|面・縁|通知の面はテーマの `popover`、縁は `border`（gpui-kit の Notification 実装）。ダークは `theme::apply_dark_surfaces` が `popover` を neutral-900・`border` を neutral-600 に引き直し、背景に溶けないようにする。ライトは `theme::apply_light_surfaces` が `border` / `input` を neutral-300 にする。|`crates/app/src/theme.rs:31`|
|本棚|書籍情報展開中、表紙取得成功/失敗、BOOTH・FANZA・DLsite・技術書典のログイン要求/同期進行/結果/失敗、ダウンロード結果を Info/Success/Error で通知する。加えて**進行中**も通知する（`download_notice_message`。「ダウンロード中です…（N 件 / NN%）」/ 取り込み段階は「取り込み中です…」。文言が変わったときだけ積む）。|`crates/app/src/views/bookshelf.rs:794`|`crates/app/src/views/bookshelf.rs:1688-1690,1884-1896,2255-2272,2452-2467,2481-2498,2529-2545,2559-2576,2607-2623,2637-2649,2684-2697,3207-3214`|
|設定|設定画面の `show_toast` は常に種別未指定の Info。ログアウト、Drive 同期、保存先移動、ローカル削除、非表示解除、同期情報クリアで使用する。|`crates/app/src/views/settings.rs:601-604,637-674,706-750,859-878,992-1004,1062,2348,2506`|
|Workspace Drive|復元結果と Drive 同期結果は種別未指定の Info として設定する。失敗文でも Error 種別へ切り替えない。|`crates/app/src/workspace.rs:612-615,1448-1450`|
|チェックリスト|グローバル通知ではなく画面ローカルの `toast` / `error` をインライン表示する。未ログイン同期は「ログインしてから同期してください」、同期成功は「チェックリストを同期しました（{count} 件）」、未ログインお気に入り取込は「ログインしてから実行してください」、成功は「お気に入りを {count} 件取り込みました」、空試し読みは「試し読み画像がありません」。|`crates/app/src/views/checklist.rs:399-486,560-587`|
