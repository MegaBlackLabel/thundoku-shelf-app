# Thundoku Shelf

Webサイトで購入した電子書籍の同人誌を、デスクトップで閲覧するビューアーアプリです。

> **本アプリは非公式のアプリです。** 個人が開発しているもので、DMM.com、FANZA、DLsite、BOOTH、
> 技術書典をはじめとする各サービスの運営会社とは提携・関連しておらず、各社による提供・承認・
> 推奨・サポートを受けたものではありません。各サービスの名称は、それぞれの権利者に帰属します。

> **これはアルファ版です。** 開発中で、予告なく仕様が変わったり、データの互換性が壊れたりすることがあります。大切なデータは Google Drive へのバックアップを併用してください。

## 対象（取り込める本）

**購入済みで、DRM の無い（非DRM）同人誌**が対象です。購入していないコンテンツや、DRM で保護されたコンテンツは取り込めません。

DRM で保護された作品は**このアプリでは開けない**ため、各ストアのサイトや公式ビューアーでご覧ください。

## ダウンロードとインストール

[Releases](https://github.com/MegaBlackLabel/thundoku-shelf-app/releases) からお使いの OS の zip をダウンロードして、展開して起動してください（インストーラーはありません）。

ファイル名の `x.y.z` はバージョンです（例: `thundoku-shelf-0.2.4-aarch64-macos.zip`）。

| OS | ファイル |
|---|---|
| Windows (x64) | `thundoku-shelf-x.y.z-x86_64-windows.zip` |
| macOS (Apple Silicon) | `thundoku-shelf-x.y.z-aarch64-macos.zip` |
| macOS (Intel) | `thundoku-shelf-x.y.z-x86_64-macos.zip` |

- **Windows**: 展開したフォルダに `pdfium.dll`（PDF 表示用）が入っています。**exe と同じフォルダに置いたまま**使ってください。初回起動時に SmartScreen の警告が出たら「詳細情報」→「実行」で進めます。

### macOS での起動

> [!NOTE]
> **これから配布する版は Apple の公証（Notarization）済みです。** `ThundokuShelf.app` を Applications に移してダブルクリックすれば、そのまま起動できます。

## 使い方

1. 起動すると本棚が開きます（初回は空です）
2. **サイドバー下部のアカウント**から、購入元のストアにログインします
3. 本棚の**同期**ボタンで購入本を取り込みます（表紙はこのときに取得され、書籍ファイルは本を開いたときにダウンロードされます）
4. 本をクリックするとビューアーで開きます。右クリックメニューからお気に入り・タグ・付箋などを操作できます

## 主な機能

- **本棚** — カード / リスト表示の切り替え（選択した表示形式は次回起動時も復元）、ストア・タグ・イベント・読書状態（未読 / 読んでいる途中 / 読了）・お気に入りでの絞り込み、検索、並び替え（購入日 / 発売日 / タイトル / 最終閲覧日 / 閲覧回数 / 閲覧時間 / サイズ）、キーボード操作（矢印 / `hjkl` / `Enter`）
- **ビューアー** — 単一ページ / 見開き / スクロールの 3 モード。ダブルクリックでズーム（2x → 6x → 解除）、ドラッグで移動。見開きの綴じ方向（右綴じ / 左綴じ）は、既定がサイトごと（技術書典は左綴じ、FANZA同人 / DLsite は右綴じ）で、ビューアで変えると**その本だけ**に効きます。通常のホイールは 1 ノッチ = 1 ページ送りで、向きは設定画面の「ビューア共通設定」で変更できます
- **付箋** — ページ単位のメモ。付箋画面から一覧して、そのページで開き直せます
- **閲覧履歴・読書統計** — いつ・何回・どれだけ読んだかを記録します
- **チェックリスト** — 技術書典のイベント・サークルの確認（技術書典ログイン中のみ利用可能）
- **ダウンロードと取り込み** — 未取得の本だけを取り込み、進捗を表示。進行中の転送は、右クリックメニューの「ダウンロード中止」または `Backspace` で中止できます
- **ストアから取り込み（同期）** — 各ストアにログインすると自動で同期が始まり、購入済みの一覧が本棚に入ります（右上の「同期」ボタンでいつでもやり直せます）
- **自動タグ生成** — 取り込んだ本の情報からタグを生成（技術書典専用）
- **Google Drive バックアップ** — Google でログインすると、**取り込んだ書籍ファイル本体**（ページ画像を含むアプリの形式 `.opfspack` に変換したもの）と**本棚の DB**を Google Drive にバックアップ・同期できます（同期するのはログイン中の Google アカウントに紐づく本だけ。DB のバックアップに画像の base64 と本文テキストは含みません）。複数端末での共有も可
- **レポート（GitHub Issue）** — サイドバーの「設定」の上に「レポート」があります（ログイン不要）。不具合や要望をテンプレート付きの画面で書くと、**このアプリのリポジトリの Issue 作成画面が既定のブラウザーで開きます**。アプリは GitHub の権限（トークン）を一切持ちません。画像を添付するときは、開いた画面でドラッグ＆ドロップしてください。本文が URL に収まらない長さのときは、本文をクリップボードへコピーしてから作成画面を開きます

## データの保存場所

購入履歴・書籍ファイル・表紙などは、すべて**お使いの PC の中**に保存されます。ただし **Google Drive バックアップを ON にすると、取り込んだ書籍ファイル本体と本棚の DB が Google Drive にも保存されます**（元のダウンロードファイルをそのまま上げるのではなく、アプリの形式に変換したものを上げます）。

| OS | 場所 |
|---|---|
| Windows | `%APPDATA%\thundoku-shelf\` |
| macOS | `~/Library/Application Support/thundoku-shelf/` |

- アプリが外部と通信するのは、**各ストアへのログイン・同期**、**Google Drive へのバックアップ**、**レポートのテンプレート取得（GitHub・匿名）**のときです（ほかに、タグ生成のために Zenn のタグ一覧を参照します）。**GitHub へのログインやトークンの保存は行いません**（Issue はブラウザーで作成します）。アクセス解析・広告・利用状況の送信はありません
- 保存先は設定画面から変更できます（バックアップの対象にもなります）
- ストアのログイン状態（セッション Cookie）は、**OS の資格情報ストア（Windows: 資格情報マネージャー / macOS: キーチェーン）にある専用の鍵で暗号化**して保存します。**保存期間は 7 日**で、それを過ぎたセッションは起動時に破棄して**再ログイン**を求めます（期限は暗号文の中に入っているため、DB を書き換えても延ばせません）。「ログアウト」でいつでも削除できます

## 本の鍵（暗号化と復元）

取り込んだ本は `.opfspack` というアプリ独自の形式で保存され、**アカウントごとに作られる乱数の鍵**で暗号化されます（Google のアカウント情報から鍵を作ることはしません）。鍵は次の 2 か所に保存されます。

| 場所 | 内容 |
|---|---|
| お使いの PC | OS の資格情報ストア（Windows: 資格情報マネージャー / macOS: キーチェーン）に、用途別の鍵として保存 |
| Google Drive | `thundoku-keys.json` に、**「Google アカウントで解ける形」と「パスフレーズで解ける形」の 2 通り**でラップして保存（Google Drive バックアップを使う場合） |

- **パスフレーズの設定を推奨します**。設定すると、Google アカウントの情報を知っているだけでは鍵を解けなくなり、端末を失ってもバックアップから復元できます（アカウントを乗っ取られても、取り込んだ本の中身は守られます）。設定画面の一番上の「本の鍵」から設定・変更・解除でき、**ログイン直後に未設定なら案内が出ます**
- **鍵の控えをすべて失うと、取り込んだ本は復号できません**（ストアから取り込み直すことはできます）。本棚 DB のバックアップ（`thundoku-backup.json`）も同じ鍵で暗号化されます
- 旧形式（v2）の `.opfspack` はこの方式に対応していないため**開けません**。お手数ですがストアから取り込み直してください

## 困ったときは

- **不具合・要望の報告**: アプリの「レポート」機能から（Issue 作成画面がブラウザーで開きます）、または [Issues](https://github.com/MegaBlackLabel/thundoku-shelf-app/issues/new/choose) へどうぞ。Issue テンプレートを用意しています
- **バージョンの確認**: 「このアプリについて」画面の下部に出ています

## 既知の制約

- **アルファ版です**。仕様変更やデータの非互換が起こりえます（バックアップの併用を推奨）
- 各ストアへの通信の `User-Agent` は、**DLsite / FANZA / BOOTH と表紙取得では既定でアプリの自認**（`ThundokuShelf/<version>（+ リポジトリ URL）`）です（ブラウザを装いません）。技術書典だけは固定のブラウザ UA を使っています。DLsite / FANZA / BOOTH / 表紙取得は、環境変数（`THUNDOKU_DLSITE_UA` / `THUNDOKU_FANZA_UA` / `THUNDOKU_BOOTH_UA` / `THUNDOKU_COVER_UA`）で差し替えられます。これは**再ビルドせずに戻すための緊急避難**で、ブラウザの偽装を推奨するものではありません
- 対象は購入済み・非DRM の同人誌のみです（DRM 付きの作品の閲覧先は「対象（取り込める本）」を参照）
- Google ログインはバックアップ用です。**書籍を読むのにログインは不要**です
- レポートは**ブラウザーで Issue 作成画面を開く方式**です（アプリは GitHub のトークンを持ちません）。画像の添付は、開いた画面でドラッグ＆ドロップしてください
- レポートの投稿先はこのアプリのリポジトリ（`MegaBlackLabel/thundoku-shelf-app`）に固定です
- macOS 版は Developer ID で署名し、Apple の公証（Notarization）を受けています。v0.2.5 以前の配布物は未署名・未公証で、初回だけ Gatekeeper の解除が必要です（手順はその配布物に同梱の「はじめにお読みください」にあります）
